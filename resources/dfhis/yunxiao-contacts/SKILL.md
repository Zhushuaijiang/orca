## 使用方式

更新工作项负责人：
```python
updateWorkItemFields = {"assignedTo": "<userId>"}
```

添加参与者：
```python
participants = ["<userId>"]
```

## 分配决策指引

智能体分配工作项时，参考以下规则：

1. **测试负责人**：优先分配给产品/测试角色（如陈洁），非开发人员
2. **开发评审**：根据需求涉及的技术栈选择对应开发人员
3. **地区匹配**：需求标题或描述中包含地区关键词时，优先分配给对应地区联系人
4. **默认分配**：无法确定时，分配给当前需求所在项目的最近活跃开发人员
5. **系统账号**：`yunxiao_agent` 是 API 接口账号，不可分配给真实工作项
