# HIS UI 规范（28 条评审标准）

本文档是 HIS 前端代码（非医共体/YGT）UI 评审的标准依据。评审时逐条对照，
脚本 `scripts/ui-spec-review.mjs` 可自动扫描其中可机械判断的条目，其余条目由评审人核对。

## 布局规范（规范 1-5）

| ID | 规范 | 要求 |
|----|------|------|
| 1 | 页面基础背景色 | #E9E9EC（浅灰色） |
| 2 | 容器与背景层边缘间距 | 8px 边距 |
| 3 | 容器之间间距 | 8px 间距 |
| 4 | 容器内边距 | 统一 8px |
| 5 | 容器圆角 | 常规容器 4px，贴边容器 0px |

## 表格整体规范（规范 6-10）

| ID | 规范 | 要求 |
|----|------|------|
| 6 | 表格各组件间距 | 8px |
| 7 | 不同表格间距 | 16px |
| 8 | 表格内组件对齐 | 左对齐（除操作按钮组外） |
| 9 | 表格操作按钮组对齐 | 右端对齐（右上角与右下角） |
| 10 | 组件内元素对齐 | 左对齐 |

## 表格数据区规范（规范 11-15）

| ID | 规范 | 要求 |
|----|------|------|
| 11 | 表格组件 | 使用新的 Dx 表格（`df-dx-table`，DfDxTable，基于 DevExtreme DataGrid，来源于 df-web-bui） |
| 12 | 表格自适应 | 撑满容器 |
| 13 | 表格内部空间 | 占满可用空间 |
| 14 | 表格列宽 | 比例协调 |
| 15 | 滚动条显示 | 默认不显示 |

## 表单规范（规范 16-18）

| ID | 规范 | 要求 |
|----|------|------|
| 16 | 栅格系统 | 使用栅格系统 |
| 17 | Gutter 间距 | 12px |
| 18 | 表单对齐 | 标签右对齐 + 控件左对齐，或标签左对齐 + 控件左对齐 |

## 颜色规范（规范 19-20）

| ID | 规范 | 要求 |
|----|------|------|
| 19 | 文字颜色 | #1A1A1A，用透明度区分层级 |
| 20 | 功能色 | 使用推荐功能色 |

## 文字规范（规范 21-23）

| ID | 规范 | 要求 |
|----|------|------|
| 21 | 常规正文行高 | 22px |
| 22 | 表格数据区域行高 | 18px |
| 23 | 提示信息强调格式 | 使用【】包裹（病人姓名、病案号、药品名称、项目名称等） |

## 按钮规范（规范 24-26）

| ID | 规范 | 要求 |
|----|------|------|
| 24 | 左侧按钮组 | 最重要、最起始的操作放最左边 |
| 25 | 右侧按钮组 | 最重要、最起始的操作放最右边 |
| 26 | 按钮颜色 | 使用颜色规范里的功能色 |

## 弹窗规范（规范 27-28）

| ID | 规范 | 要求 |
|----|------|------|
| 27 | 大弹窗默认尺寸 | 宽度 = 遮罩宽度 × 90%，高度 = 遮罩高度 × 80% |
| 28 | 最大弹窗尺寸 | 可以充满页面 |

## 代码评审速查

- **背景色**：页面级 `#E9E9EC`，无硬编码其它浅色页面底色
- **边距/内距**：布局 8px，表单 gutter 12px，表格间 16px
- **圆角**：常规 4px，贴边 0px
- **文字颜色**：基础 `#1A1A1A` + 透明度区分层级
- **行高**：正文 22px，表格数据区 18px
- **对齐**：组件左对齐，操作按钮组右对齐
- **表格**：使用新的 Dx 表格（`df-dx-table`，DfDxTable）
- **强调文本**：病人姓名、药品名称等用【】包裹
