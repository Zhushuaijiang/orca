## 常见问题

### 独立运行白屏

优先检查三件事：

1. 主应用约定的 `/api` 代理是否已在 `vite.config.ts` 配好
2. 如果页面依赖登录态，是否已通过 `devDebug` 或 mock 身份绕开认证
3. 如果页面依赖 common-biz，`VITE_COMMON_BIZ_ENTRY` 是否指向可访问入口

### 主应用加载白屏

```js
// 主应用控制台
sessionStorage.setItem('devDebug', 'test');
sessionStorage.setItem('{子应用名}', 'http://localhost:{端口}');
```

### common-biz 组件不显示

1. 确认 `df-web-common-ygt-biz` 在 8102 端口运行
2. 检查 `useCommonBizProvider().providerLoaded` 是否 `true`
3. 检查 `useCommonBizProvider().errorMessage` 是否有错误
