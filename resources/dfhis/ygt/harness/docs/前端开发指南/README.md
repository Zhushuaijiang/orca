## 阅读路径

### 子应用开发者

```
01-系统全景 → 02-架构设计 → 03-权限系统 → 04-API客户端 →
各自子应用的快速上手文档
```

需要使用共享业务组件时加读 `05-共享业务组件接入`，使用表格时加读 `06-DevExtreme集成`。涉及页面布局、查询条件、按钮区或子应用间距时，必须同时阅读 `08-布局系统` 中的“子应用页面与查询栏约束”。

### 主应用开发者

```
01-系统全景 → 02-架构设计 → 08-布局系统 → 09-状态管理 →
10-登录认证 → 11-子应用注册与加载 → 12-共享能力
```

### 新子应用搭建

1. 阅读 `01-系统全景` 了解整体架构
2. 复制 `子应用模板/快速上手模板.md` 到新子应用仓库
3. 填写项目特有信息（端口、activeRule、页面清单等）
4. 参考现有子应用的 `src/main.ts` 搭建入口

### 布局调整必读

批量调整页面样式时先改主应用桥接和子应用主题桥接，再删页面私有样式。查询栏的按钮顺序固定为“查询字段 -> 查询按钮 -> 后续查询相关按钮”，按钮不能单独居右；页面根边距、查询字段宽度和块间距必须走统一变量，调整后至少验证 `879px / 1092px / 1365px / 1920px` 四档宽度。

## 新建子应用清单

- [ ] 复制 `df-web-template-ygt` 作为基础
- [ ] 修改 `vite.config.ts` 中的 `SUB_APP_NAME` 和端口
- [ ] 修改 `.env.*` 环境变量
- [ ] 创建 `docs/前端开发指南/` 并复制快速上手模板
- [ ] 在主应用 `src/micro/apps.ts` 注册新子应用
- [ ] 配置主应用菜单项（后端或 Mock）
- [ ] 接入统一布局桥接变量，确认查询栏按钮不右浮、页面外沿对齐
