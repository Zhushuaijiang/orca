## 环境要求

- Node.js >= 18
- pnpm >= 8

## 启动顺序

联调时按顺序启动：

```bash
# 1. 共享业务组件（多个子应用依赖）
cd df-web-common-ygt-biz && pnpm dev    # :8102

# 2. 你正在开发的子应用
cd df-web-ygt-biz-xxx && pnpm dev       # :810x

# 3. 主应用
cd df-web-ygt-main && pnpm dev          # :8000
```

子应用独立运行时，所有权限默认放行，common-biz 通过 `.env.development` 的 `VITE_COMMON_BIZ_ENTRY` 加载。

## API 与网关约定

- 开发环境：`runtimeConfig.apiBase = ''`，`/api` 通过 [vite.config.ts](../../frontend/df-web-ygt-main/vite.config.ts) 代理到真实后端。
- 生产环境：`runtimeConfig.apiBase = ''`，由 Nginx / 网关同源转发 `/api`、`/auth`、`/monitor`、`/ws`。
- WebSocket：生产默认根据当前页面域名拼出 `/ws`，不再写死 `localhost:9000`。

## 主应用 Debug 模式

主应用内置 Debug 系统（`src/micro/debug.ts`），可通过 `sessionStorage` 覆盖子应用入口：

```js
// 在主应用页面控制台中
sessionStorage.setItem('microDebug', 'test');
sessionStorage.setItem('df-web-ygt-biz-huanzhe360', 'http://localhost:8106');
// 将子应用名替换为你要调试的子应用
```

开发态还提供按钮注册调试页：

```text
/system/devtools/button-codes?mockButtons=200
```

该地址会绕过登录守卫并生成模拟按钮注册数据，用于校验 `DfButton finalCode`、显隐覆盖和 TreeList 滚动行为。
