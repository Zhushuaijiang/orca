# 09 - 状态管理（Pinia Stores）

## 概览

主应用当前使用 13 个 Pinia Store 管理全局状态，其中 5 个通过 `SharedProps` 传递给子应用（只读）。

## 传递给子应用的 Stores

### useUserStore

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `string` | 用户 ID |
| `userName` | `string` | 用户名 |
| `realName` | `string` | 真实姓名 |
| `roles` | `string[]` | 角色列表 |
| `avatar` | `string` | 头像 URL |
| `hasRole(...roles)` | `function` | 角色判断 |

数据来源：登录响应 `POST /auth/login` 返回，页面刷新时通过 `GET /auth/me` 恢复。

### useTenantStore

| 字段 | 类型 | 说明 |
|------|------|------|
| `hospitalCode` | `string` | 医院编码 |
| `hospitalName` | `string` | 医院名称 |
| `campusList` | `Campus[]` | 院区列表 |
| `currentCampus` | `Campus` | 当前院区 |
| `switchCampus(campus)` | `function` | 切换院区（触发 `switchCtx` 事件） |

数据来源：登录响应中的 `tenant` 字段，开发态由守卫/登录流程注入 mock 租户。

### useMenuStore

| 字段 | 类型 | 说明 |
|------|------|------|
| `menus` | `MenuItem[]` | 菜单树 |
| `flatMenus` | `MenuItem[]` | 扁平化菜单（含隐藏菜单） |
| `permissions` | `string[]` | 所有权限码集合 |
| `menuMap` | `Map<string, MenuItem>` | path → MenuItem 映射 |
| `fetchMenus()` | `function` | 加载菜单 `GET /api/sys/caidan/tree` |
| `hasPathAccess(path)` | `function` | 检查路径访问权限 |

菜单接口失败时会回退 `src/store/menuSnapshot.json`，保证开发态和离线排查场景仍可生成动态路由。

### useDictStore

| 字段 | 类型 | 说明 |
|------|------|------|
| `cache` | `Map<string, DictItem[]>` | 字典缓存 |
| `get(code)` | `function` | 获取字典项列表 |
| `getLabel(code, value)` | `function` | 获取字典项标签 |
| `fetchDicts(codes?)` | `function` | 批量加载 `GET /system/dicts/batch` |

### useThemeStore

| 字段 | 类型 | 说明 |
|------|------|------|
| `mode` | `'light' \| 'dark' \| 'auto'` | 主题模式 |
| `isDark` | `boolean` | 当前是否深色 |
| `dxTheme` | `DxThemeKey` | DX 主题 key（22 套） |
| `densityPreference` | `'comfortable' \| 'compact' \| 'auto'` | 密度偏好 |
| `currentDensity` | `string` | 当前实际密度 |
| `setTheme(mode)` | `function` | 切换主题 |
| `setDxTheme(key)` | `function` | 切换 DX 主题 |
| `setDensity(pref)` | `function` | 切换密度 |

密度自动切换逻辑：视口 <= 1366x820 且偏好为 `auto` 时自动切换 `compact`。

## 主应用内部 Stores

### useTabStore

| 字段 | 类型 | 说明 |
|------|------|------|
| `tabs` | `Tab[]` | 标签页列表（最多 20 个） |
| `activeTab` | `Tab \| null` | 当前激活标签 |
| `addTab(tab)` | `function` | 添加标签 |
| `removeTab(path)` | `function` | 关闭标签 |
| `activateTab(path)` | `function` | 激活标签 |

标签页由子应用路由后置守卫 `eventBus.emit('sub-app:route-change')` 驱动。

### useLayoutStore

| 字段 | 类型 | 说明 |
|------|------|------|
| `isCollapsed` | `boolean` | 侧边栏是否折叠 |
| `isFullscreen` | `boolean` | 是否全屏模式 |
| `toggleSidebar()` | `function` | 切换侧边栏 |
| `toggleFullscreen()` | `function` | 切换全屏 |

### useSessionStore

| 字段 | 类型 | 说明 |
|------|------|------|
| `isActive` | `boolean` | 会话是否活跃 |
| `lastActivity` | `number` | 最后活跃时间戳 |
| `startMonitoring()` | `function` | 启动会话监控 |
| `stopMonitoring()` | `function` | 停止监控 |
| `renewSession()` | `function` | 续期会话 |

监控用户活动（鼠标/键盘），超时自动登出。

### useFavoritesStore

| 字段 | 类型 | 说明 |
|------|------|------|
| `favorites` | `MenuItem[]` | 收藏菜单列表 |
| `addFavorite(menu)` | `function` | 添加收藏 |
| `removeFavorite(id)` | `function` | 移除收藏 |

### usePreferenceStore

| 字段 | 类型 | 说明 |
|------|------|------|
| `preferences` | `Record<string, unknown>` | 用户偏好 |
| `setPreference(key, value)` | `function` | 设置偏好 |

### useButtonVisibilityStore

| 字段 | 类型 | 说明 |
|------|------|------|
| `overrides` | `Record<string, boolean>` | `finalCode -> visible` 覆盖表 |
| `hiddenCount` | `ComputedRef<number>` | 当前被隐藏按钮数 |
| `isVisible(code)` | `function` | 读取按钮当前是否可见 |
| `setVisibility(code, visible)` | `function` | 设置单个按钮显隐 |
| `clearOverride(code)` | `function` | 清除单个覆盖 |
| `clearAll()` | `function` | 清除全部覆盖 |

数据持久化到 `localStorage['df-web-button-visibility']`，配合 `setupButtonVisibilitySync(router)` 把覆盖值同步到实际 `DfButton` DOM。

### useRightDockStore

| 字段 | 类型 | 说明 |
|------|------|------|
| `items` | `DockItem[]` | 右侧栏工具项 |
| `visible` | `boolean` | 是否显示 |
| `setItems(scope, items)` | `function` | 注册工具（子应用调用） |
| `clearItems(scope)` | `function` | 清理工具（子应用离开时调用） |

### useShellUiStore

| 字段 | 类型 | 说明 |
|------|------|------|
| `commandCenterVisible` | `boolean` | 命令面板是否显示 |
| `preferenceCenterVisible` | `boolean` | 偏好面板是否显示 |
| `overlayVisible` | `boolean` | 覆盖面板是否显示 |

## Store 与子应用的交互

```
主应用 Store          →  SharedProps.store  →  子应用 useMainApp().store
useUserStore          →  store.user         →  store?.user?.realName
useTenantStore        →  store.tenant       →  store?.tenant?.hospitalName
useMenuStore          →  store.menu         →  store?.menu?.permissions
useDictStore          →  store.dict         →  store?.dict?.get(code)
useThemeStore         →  store.theme        →  store?.theme?.isDark
```

子应用只能**读取** Store 状态，不能直接修改。如需触发变更，通过 `actions` 或 `eventBus` 通知主应用。
