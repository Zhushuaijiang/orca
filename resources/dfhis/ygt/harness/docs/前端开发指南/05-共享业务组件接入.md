## common-biz Provider 内部机制

### 注册函数

`df-web-common-ygt-biz/src/provider/index.ts` 暴露：

```ts
// 静态元数据
export const commonBizProvider = {
  name: 'df-web-common-ygt-biz',
  version: '2026.04',
  components: { encounterCard: {...}, patientStatusCard: {...} }
};

// 注册函数 — 创建 Custom Element 并注册到浏览器
export function registerCommonBizProvider(options?) {
  // 1. 解析 tag 名（支持 options.tagOverrides 自定义）
  // 2. 检查 customElements.get() 避免重复注册
  // 3. customElements.define(tagName, constructor)
  // 4. 返回 { components, encounterCardTag, ... }
}
```

### 关键约束

浏览器规定 "一个 tag 只能有一个 constructor"，因此 `registerCommonBizProvider` 每次调用都创建新的 `defineCustomElement()` 构造器，不能缓存复用。

### 数据标准化

`src/provider/encounterSummary.ts` 提供 `parseEncounterSummary(json)` → `normalizeEncounterSummary(raw)`：

- `safeText()`: null/undefined/empty → `'--'`
- `formatCurrency()`: `Intl.NumberFormat` 格式化为人民币
- `normalizeAlerts()`: 校验告警级别
- 场景感知默认值（门诊 "门诊就诊" / 住院 "住院在院"）

## 页面使用方式

```vue
<script setup>
import { useCommonBizProvider } from '@/composables/useCommonBizProvider';
import type { CommonBizActionDetail } from '@/composables/useCommonBizProvider';

const { providerEntry, providerVersion, providerLoaded } = useCommonBizProvider();
</script>

<template>
  <CommonBizEncounterCard
    :summary-json="summaryJson"
    :source-app="sourceApp"
    :service-entry="providerEntry"
    :provider-version="providerVersion || 'unknown'"
    @common-biz-action="handleAction"
  />
</template>
```

### 组件 Props

| Vue 属性 | Custom Element 属性 | 类型 | 说明 |
|----------|-------------------|------|------|
| `summaryJson` | `summary-json` | `string` | 就诊摘要 JSON 字符串 |
| `sourceApp` | `source-app` | `string` | 来源子应用标识 |
| `serviceEntry` | `service-entry` | `string` | common-biz 服务入口 |
| `providerVersion` | `provider-version` | `string` | provider 版本号 |

### 事件处理

```ts
function handleAction(event: Event) {
  const detail = (event as CustomEvent<CommonBizActionDetail>).detail;
  // detail: { action, scene, encounterId, encounterNo, patientId, patientName?, alertCount? }

  switch (detail.action) {
    case 'alerts': // 查看提醒
      actions.showNotify(`${detail.patientName} 有 ${detail.alertCount} 条提醒`, 'warning');
      break;
    case 'status': // 状态追踪
      actions.showNotify(`状态：${summary.statusText}`, 'info');
      break;
    case 'detail': // 查看详情
      router.push(`/detail/${detail.encounterId}?scene=${detail.scene}`);
      break;
  }
}
```

## 新增 common-biz 组件时的流程

子应用侧无需改动——`useCommonBizProvider.ts` 自动遍历 provider 组件清单注册。

在 `df-web-common-ygt-biz` 中新增组件的标准流程：

1. 创建 `src/provider/components/newComponent/NewComponent.ce.vue`
2. 创建 `index.ts`（导出工厂函数）和 `types.ts`
3. 在 `provider/index.ts` 的 `COMPONENT_DEFINITIONS` 中添加新条目
4. 运行 `pnpm build` 生成 provider 模块
