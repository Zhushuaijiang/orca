# 12 - 共享能力

主应用提供一系列共享能力，子应用通过 `useMainApp().actions` 或 `eventBus` 使用。

## 事件总线（`src/shared/eventBus.ts`）

基于 `mitt` 的类型化事件总线。

### 内置事件

| 事件 | Payload | 触发场景 |
|------|---------|----------|
| `login` | `unknown` | 用户登录成功 |
| `logout` | `void` | 用户登出 |
| `switchCtx` | `{ hospitalCode: string }` | 院区切换 |
| `notify` | `{ type, message }` | 全局通知 |
| `message` | `{ id, title, body }` | 新消息到达 |

### 子应用使用

```ts
const { eventBus } = useMainApp();
eventBus?.on('switchCtx', (ctx) => { console.log('切换到', ctx.hospitalCode); });
eventBus?.emit('sub-app:route-change', { path, name, title });
```

## 跨应用导航（`src/shared/openApp.ts`）

### openApp

```ts
import { useMainApp } from '@/composables/useMainApp';
const { actions } = useMainApp();

// navigate 模式 — 路由跳转
actions.openApp({ path: '/biz-base/ward-list', mode: 'navigate' });

// dialog 模式 — iframe 弹窗
actions.openApp({
  path: '/biz-huanzhe360/patient/123',
  mode: 'dialog',
  title: '患者详情',
  width: 800,
  height: 600,
  onClose: (result) => { console.log('弹窗关闭', result); },
});
```

### closeAppDialog

```ts
actions.closeAppDialog(resultValue);
```

## 水印（`src/shared/watermark.ts`）

### 实现原理

1. 使用 Canvas 绘制旋转 -20 度的半透明文字
2. 转为 base64 PNG 作为 `background-image` 平铺
3. 创建 `position: fixed; z-index: 99998; pointer-events: none` 的覆盖层
4. MutationObserver 防删除保护 — 水印被删除时自动重建

### 使用

```ts
actions.setWatermark('张三 医生');
actions.clearWatermark();
```

主应用在登录成功后自动设置水印。

## 按钮显隐覆盖（主应用）

主应用新增了一套基于 `DfButton.finalCode` 的按钮显隐治理能力。

### 组成

- `useButtonVisibilityStore`：持久化 `finalCode -> visible`
- `setupButtonVisibilitySync(router)`：把 store 覆盖值重放到真实按钮 DOM
- 调试页：`/system/devtools/button-codes`

### 同步时机

- store 变化
- 路由切换完成后
- DOM 发生增删（`MutationObserver`）

### 数据落点

```ts
localStorage['df-web-button-visibility']
```

这套能力主要用于主应用联调与治理，不替代后端权限码本身。

## 权限工具（`src/shared/permission.ts`）

### 函数式

```ts
import { checkPermission, hasRole } from '@/shared/permission';

checkPermission('huanzhe360:patient:add'); // → boolean
hasRole('admin');                           // → boolean
```

### v-permission 指令（主应用版）

```vue
<button v-permission="'admin:user:delete'">删除用户</button>
```

主应用的 `v-permission` 实现为 **DOM 移除**（`removeChild`），子应用实现为 **CSS 隐藏**（`display:none`）。

## DevExtreme 主题（`src/shared/dxTheme.ts`）

### 主题列表

| 系列 | 主题 Key |
|------|----------|
| Generic | `dx.light`, `dx.dark`, `dx.contrast`, `dx.contrast-dark` 等 |
| Fluent | `dx.fluent.blue.light`, `dx.fluent.blue.dark`, ... |
| Material | `dx.material.blue.light`, `dx.material.blue.dark`, ... |

共 22 套主题。

### 加载机制

```ts
loadDxTheme('fluent.blue.light.compact');
```

- DEV: 从 `/node_modules/devextreme-dist/css/` 加载
- PROD: 从 `/dx-themes/` 加载
- 通过动态替换 `<link id="dx-theme-link">` 实现热切换
- 默认主题为 `fluent.blue.light.compact`，对应 `dx.fluent.blue.light.compact.css`
- 子应用在 qiankun 模式下跟随主应用主题，不再打包或注入 `devextreme-dist/css/*`
