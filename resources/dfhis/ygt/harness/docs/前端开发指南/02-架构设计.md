## `__SHARED_LIBS__` 共享机制

主应用 `main.ts` 在启动时将 5 个包挂载到 `window.__SHARED_LIBS__`：

```ts
// 主应用 main.ts
window.__SHARED_LIBS__ = {
  vue: await import('vue'),
  pinia: await import('pinia'),
  'vue-router': await import('vue-router'),
  '@df/ui': await import('@df/ui'),
  '@df/utils': await import('@df/utils'),
};
```

子应用生产构建时外部化 `vue` 和 `pinia`：

```ts
// 子应用 vite.config.ts
external: isDev ? [] : ['vue', 'pinia'],
output: {
  globals: {
    vue: '__SHARED_LIBS__.vue',
    pinia: '__SHARED_LIBS__.pinia',
  },
  format: 'umd',
}
```

## SharedProps 协议

主应用在 `src/micro/shared.ts` 中构建 `SharedProps`，通过 qiankun `mount(props)` 传递给每个子应用：

```ts
{
  store: {
    user: useUserStore(),      // 用户信息 + 角色
    tenant: useTenantStore(),  // 租户 + 院区
    menu: useMenuStore(),      // 菜单树 + 权限码
    dict: useDictStore(),      // 数据字典
    theme: useThemeStore(),    // 主题模式 + DX 主题
  },
  eventBus,                    // mitt 事件总线
  router,                      // 主应用路由
  actions: createMainAppActions(), // 12+ 个 actions
  appTitle: string,
  capabilityVersion: string,
  microAppInfo: { name, title, activeRule, capabilityVersion },
  inMicroShell: true,
}
```

## 主应用 Actions 清单

所有子应用通过 `useMainApp().actions` 获取以下能力：

| Action | 说明 | 来源 |
|--------|------|------|
| `openApp(opts)` | 跨应用导航（navigate/dialog 模式） | `shared/openApp.ts` |
| `closeAppDialog()` | 关闭 dialog 模式的应用弹窗 | `shared/openApp.ts` |
| `showDialog(opts)` | 全局弹窗 | `shared/dialog.ts` |
| `showConfirm(opts)` | 确认对话框 | `shared/dialog.ts` |
| `showNotify(msg, type)` | 轻量通知 | `shared/dialog.ts` |
| `checkPermission(code)` | 权限检查 | `shared/permission.ts` |
| `setWatermark(text)` | 设置水印 | `shared/watermark.ts` |
| `clearWatermark()` | 清除水印 | `shared/watermark.ts` |
| `getTraceId()` | 获取追踪 ID | `monitor/traceId.ts` |
| `setRightDockItems(scope, items)` | 注册右侧栏工具 | `store/useRightDockStore.ts` |
| `clearRightDockItems(scope)` | 清理右侧栏 | `store/useRightDockStore.ts` |
| `getMicroAppEntry(name)` | 获取子应用入口 URL | `micro/apps.ts` |
| `getMicroAppConfig(name)` | 获取子应用完整配置 | `micro/apps.ts` |

## 共享 HTTP 初始化

主应用在 `main.ts` 中按如下顺序启动共享 HTTP：

```ts
app.use(pinia);
setupSharedApi();
app.use(router);
```

`setupSharedApi()` 会把以下能力注入 `@df/utils/http`：

- `baseURL`: `runtimeConfig.apiBase`
- `getToken`: 从 `src/auth/token.ts` 读取 JWT
- `getContext`: 自动补齐 `tenantId / userId / userName`
- `getTraceId`: 复用主应用会话级 TraceId
- `onUnauthorized`: 401 去重刷新队列
- `onForbidden`: 403 跳转 `/403?from=...`

### 运行时地址策略

- 开发环境 `config/apps/apps.dev.js`：`apiBase = ''`，`/api` 由 Vite 代理到真实后端。
- 生产环境 `config/apps/apps.prod.js`：`apiBase = ''`，`stompUrl` 基于当前页面域名动态生成。
- 生产部署必须由网关同源转发 `/api`、`/auth`、`/monitor`、`/ws`，前端产物不再写死后端 IP。

## 主应用 Stores（子应用只读快照）

| Store | 关键字段 | 说明 |
|-------|---------|------|
| `useUserStore` | `id`, `userName`, `realName`, `roles` | 用户信息，支持 `hasRole()` |
| `useTenantStore` | `hospitalCode`, `hospitalName`, `campusList`, `currentCampus` | 支持院区切换（触发 `switchCtx` 事件） |
| `useMenuStore` | `menus`, `flatMenus`, `permissions`, `menuMap` | 菜单来自 `/api/sys/caidan/tree`，失败回退 `menuSnapshot.json` |
| `useDictStore` | `cache Map`, `get(code)`, `getLabel(code, value)` | 批量加载字典 `/system/dicts/batch` |
| `useThemeStore` | `mode`, `dxTheme`, `densityPreference` | 22 套 DX 主题，自动密度切换 |

## 双模式运行

### 独立模式（standalone）

```bash
pnpm dev  →  http://localhost:81xx
```

- 所有依赖从 `devDependencies` 加载
- `actions`/`store`/`eventBus` 使用 fallback（`useMainApp.ts` 中定义）
- 权限全部放行
- common-biz 通过 `VITE_COMMON_BIZ_ENTRY` 加载
- DX locale/CSS 通过 `require()` 同步加载

### qiankun 模式（micro）

- 主应用加载，通过 `mount(props)` 接收 `SharedProps`
- Vue / Pinia 通过 `__SHARED_LIBS__` 共享
- DX locale/CSS 由主应用提供
- 权限由主应用 `actions.checkPermission()` 控制
- common-biz 通过 `actions.getMicroAppEntry('df-web-common-ygt-biz')` 获取入口

判断当前模式：

```ts
import { useMainApp } from '@/composables/useMainApp';
const { isMicro } = useMainApp();
```

## 事件总线

主应用使用 `mitt` 实现类型化事件总线（`src/shared/eventBus.ts`）：

```ts
type EventMap = {
  login: unknown;
  logout: void;
  switchCtx: { hospitalCode: string };
  notify: { type: 'success'|'warning'|'error'|'info'; message: string };
  message: { id: string; title: string; body: string };
};
```

子应用通过 `eventBus.on/emit/off` 参与通信。子应用路由切换时，后置守卫通过 `eventBus.emit('sub-app:route-change')` 通知主应用同步标签页。

## 依赖共享策略

| 类别 | dependencies | devDependencies | 生产构建 |
|------|-------------|-----------------|----------|
| vue / pinia | 空 | vue, pinia | external → `__SHARED_LIBS__` |
| vue-router | 空 | vue-router | 子应用自行打包 |
| @df/ui | 空 | @df/ui | 子应用自行打包 |
| @df/utils | 空 | @df/utils | 子应用自行打包 |
| devextreme | 空 | devextreme* | 子应用自行打包 |

> **主应用约定**：子应用应从包根路径 import（如 `@df/utils`），不要依赖子路径 import 命中主应用共享单例。主应用自身源码可以直接使用 `@df/utils/http`，但这不代表子应用构建时也能共享该子路径模块。

## 子应用标准目录结构

所有子应用遵循相同的目录约定：

```
df-web-ygt-biz-xxx/
├── .env / .env.development / .env.production   # 环境变量
├── .npmrc                        # @df scope 私有源
├── eslint.config.js              # ESLint flat config
├── index.html                    # HTML 入口
├── tsconfig.json                 # ES2022 + strict
├── vite.config.ts                # Vite + qiankun + DX 许可证 + 外部化
├── vitest.config.ts              # jsdom + v8 coverage
└── src/
    ├── main.ts                   # qiankun 生命周期 + onCleanup + 独立运行
    ├── App.vue                   # 根组件（错误边界 + 主题跟随）
    ├── api/
    │   └── client.ts             # ofetch 封装
    ├── composables/
    │   ├── useMainApp.ts         # 主应用上下文
    │   ├── usePermission.ts      # 权限
    │   ├── useTheme.ts           # 主题跟随 + usePopupContainer
    │   ├── useLogger.ts          # 双通道日志
    │   └── useCommonBizProvider.ts # provider 加载 + Vue 组件桥接
    ├── directives/
    │   └── permission.ts         # v-permission
    ├── plugins/
    │   └── df-ui.ts              # @df/ui 自动扫描全局注册
    ├── router/
    │   ├── index.ts              # 路由定义
    │   └── guards.ts             # 路由守卫
    ├── types/
    │   ├── global.d.ts           # SharedProps / UserInfo 等类型
    │   └── global-components.d.ts # 全局组件类型
    └── views/                    # 业务页面
```
