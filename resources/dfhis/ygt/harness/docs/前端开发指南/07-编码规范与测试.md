## TypeScript 配置

所有项目统一：

```json
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "ESNext",
    "moduleResolution": "Bundler",
    "strict": true,
    "jsx": "preserve",
    "noEmit": true,
    "baseUrl": ".",
    "paths": { "@/*": ["src/*"] },
    "types": ["vite/client"]
  }
}
```

路径别名：`@/` → `src/`

## ESLint 配置（flat config）

继承规则：
- `js.configs.recommended`
- `tseslint.configs.recommended`
- `pluginVue.configs['flat/recommended']`

自定义规则：

| 规则 | 级别 | 说明 |
|------|------|------|
| `@typescript-eslint/no-explicit-any` | warn | 允许 any 但警告 |
| `@typescript-eslint/no-unused-vars` | warn | `_` 前缀忽略 |
| `@typescript-eslint/no-non-null-assertion` | off | 允许 `!.` |
| `vue/multi-word-component-names` | off | 允许单词组件名 |
| `vue/no-v-html` | warn | 警告 |
| `vue/require-default-prop` | off | 不强制默认值 |

## 编码约定

### Vue 组件顺序

```vue
<template> ... </template>
<script setup lang="ts"> ... </script>
<style scoped> ... </style>
```

### 命名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| 组件文件 | PascalCase | `HomePage.vue` |
| composable | camelCase, use 前缀 | `usePermission.ts` |
| 函数 | camelCase | `getPatientList()` |
| 常量 | UPPER_SNAKE_CASE | `COMMON_BIZ_APP_NAME` |
| 类型/接口 | PascalCase | `UserInfo` |
| CSS | BEM | `home-page__status` |
| Custom Element tag | kebab-case, `common-biz-` 前缀 | `common-biz-encounter-card` |
| 全局组件名 | PascalCase, `CommonBiz` 前缀 | `CommonBizEncounterCard` |

### 导入顺序

```ts
// 1. Vue 核心
import { ref, computed } from 'vue';
// 2. 第三方库
import { useRouter } from 'vue-router';
// 3. 内部模块（@/ 别名）
import { useMainApp } from '@/composables/useMainApp';
// 4. 类型
import type { UserInfo } from '@/types/something';
```

### 样式

- 始终 `<style scoped>`
- BEM 命名：`block__element--modifier`
- 响应式断点：`@media (max-width: 960px)`

```ts
  coverage: {
    provider: 'v8',
    include: ['src/**/*.{ts,vue}'],
    exclude: ['src/**/*.d.ts', 'src/main.ts', 'src/views/NotFound.vue'],
  },
}
```

## 测试文件组织

约定：`__tests__/{module}.test.ts`，与源文件同级目录。

## 测试最佳实践

### 1. Mock 外部依赖

```ts
vi.mock('@/composables/useMainApp', () => ({ useMainApp: vi.fn() }));
```

### 2. beforeEach 清理

```ts
beforeEach(() => { vi.clearAllMocks(); });
```

### 3. 测试双模式

每个 composable 都应测试独立模式和 qiankun 模式。

### 4. Custom Element 测试

使用唯一 tag 后缀避免冲突：`common-biz-xxx-test-xxx`。
