## 2. 主应用领域边界

`df-ygt-main` 只维护认证、用户、权限、租户、门户聚合等主应用领域。患者 360、基础数据、主索引、处方等业务领域不在主应用内复制 Entity、Repository 或 Service。

当前主应用领域目录参考：

```text
backend/src/main/java/com/df/ygt/main/domain/
├── auth
├── user
├── permission
├── tenant
└── portal
```

跨服务契约放在 `apis/`，业务服务 provider 不要求 implements 契约接口；consumer 通过自动配置注入代理。

## 3. 建模最小检查

1. 是否确认能力属于主应用，而不是某个 `df-ygt-biz-*` 服务。
2. Entity 是否继承脚手架基类，并遵守字段中文注释和命名规则。
3. Repository 是否继承统一基类，查询是否有分页或大结果集保护。
4. DTO 是否继承统一 DTO 基类，批量保存是否按状态分流。
5. 表结构、Nacos 配置、接口文档和验收样例是否同步更新。
