# legacy 文档说明

本目录保存早期编号入口和兼容索引。这里的文档不再作为阅读主线，也不维护独立规范正文。

## 保留原则

1. 旧文件名可能已被历史会话、团队文档或脚本引用，先迁入 `legacy/`，不直接删除。
2. legacy 文档只做跳转、索引和迁移说明，不复制前端、后端或 harness 主规范。
3. 新增规范不得放入本目录，应放入根目录主线、`前端开发指南/` 或 `后端开发指南/`。
