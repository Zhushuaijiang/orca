OAPI（df-oapi 模块）基于 DF 定制版 MagicAPI（`com.df.magicapi:2.2.2`），可在 MagicEditor Web UI 中动态创建 HTTP API 端点，无需改 Java 代码。

### 管理 API 自动化（curl）

登录获取 token（**token 在响应头 `Magic-Token` 中，不是响应体**）：

```bash
# -D 捕获响应头，Magic-Token 在其中
curl -s -D /tmp/magic_headers.txt -X POST "http://192.168.1.152:9059/magic/web/login" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "username=admin&password=123456"
TOKEN=$(grep -i "Magic-Token" /tmp/magic_headers.txt | tr -d '\r\n' | awk '{print $2}')
```

资源树（查看所有分组和脚本）：

```bash
curl -s -X POST "http://192.168.1.152:9059/magic/web/resource" \
  -H "Magic-Token: $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"node":"api"}'
```

创建分组：`POST /magic/web/resource/folder/save`（注意：DF fork 创建后返回空 ID，需再查 resource 树获取）
创建/更新脚本：`POST /magic/web/resource/file/api/save?auto=0`
获取脚本详情：`GET /magic/web/resource/file/{id}`
删除资源：`POST /magic/web/resource/delete`

### MagicScript 关键语法

- POST `application/x-www-form-urlencoded` 参数**直接注入为变量**（如 `app_id`、`code`），不能用 `request.body`
- `import` 可导入 Java 类：`import com.df.esb.jcpt.util.SM4Util`
- HTTP 调用用 `df.post(url, body, headers)`，底层 Hutool HttpRequest
- 返回值即 API 响应

### 国密工具类（com.df.esb.jcpt.util）

- `SM4Util.encryptEcb(plaintext, key)` — key 取 UTF-8 字节（非 hex 解码），SM4/ECB/PKCS5Padding
- `SM3Util.hash(bytes)` — 返回原始 byte[]，需自行转 hex
- `SM3SignUtil.sign()` — **签名格式与外部标准通常不兼容**（无 `&` 分隔符、用 `&sign_key=`、返回小写 hex），外部接口对接需手动实现签名逻辑
